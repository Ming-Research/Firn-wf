Decision: A measurement on the shared self-hosted machine runs in a session of its own whose identity, the boot, the session's number and its leader's start time, it records before it starts, registering each server it starts by its process id and start time, and the run itself when it ends, or the next run when it was cancelled, stops the leader and every process of the session while that leader still runs, and once it has ended only the registered servers, each signalled through a pidfd opened on the process found, TERM and then KILL, keeping the record and failing the run while any survives or the record does not read, because a cancelled run leaves servers that would load the host a later measurement uses, while the machine also runs other projects' runners and servers that must never be signalled, instead of matching processes by name, by a token in their environment, or by session number and start time alone.

Decision: A process of a measurement's session that is not a server and outlives its leader, such as a client or a profiler, is left to the runner, which stops a job's processes by the tracking variable in their environment, because a session's number can name another session once the leader has ended and only a registered process is known to be the measurement's, while clients and profilers keep the environment the runner reads, instead of stopping every process that still carries the session's number.

Rejected:
- Matching leftovers by command name: rejected because other projects run the same servers on the machine.
- A token in each process's environment: rejected because Redis 7.0.15 and Valkey overwrite the environment the kernel shows when they set their process titles ([setproctitle.c](https://github.com/redis/redis/blob/7.0.15/src/setproctitle.c)), so the servers a cancelled run leaves escape the match.
- Every process of the recorded session started within hours of its leader: rejected because once the session's processes have all ended its number can be reused by another session, whose processes would then match.
- A PID namespace, a systemd scope or a cgroup per measurement, which would empty itself however the run ends: rejected because the runner's account can create none of them, its user namespaces refused, no user service manager running and sudo barred ([run 37467067049](https://github.com/Ming-Research/Firn-wf/actions/runs/37467067049)); reopen if the runner's service is given a delegated cgroup.

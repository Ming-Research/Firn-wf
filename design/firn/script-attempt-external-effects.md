Decision: A declared-entry script attempt encountering PUBLISH, SPUBLISH or PUBSUB introspection requests the existing uncatchable whole-map retry before observing the registry or selecting recipients, and every whole-map attempt holds the event hub from its start together with the map and Meta, because the declared attempt can undo preceding writes while an already-running whole-map attempt has no general undo boundary for a late wider hold, instead of acquiring the hub inside an atomic body or restarting a written whole-map attempt. Declared-only scripts keep their existing targets; nonpublishing whole-map scripts also take the hub and its contention cost is unmeasured ([script integration](../../research/investigations/firn/connection-waits.md#pubsub-script-attempts)).

Decision: Publications select recipients and counts under the attempt's stable hub hold but retain delivery only in an owned private stage until the final Lua result or error reply is formed, because an abandoned attempt must publish nothing while an accepted Lua error keeps preceding effects, instead of sending on each redis.call or dropping publications when Lua raises. The accepted outer reply group commits before self-publication frames, and publications add no AOF dataset records. Actual staged deliveries prevent budget abandonment; a zero-recipient publication remains retryable because it has no external delivery to duplicate ([atomic publication](../../research/investigations/firn/connection-waits.md#atomic-publication-not-a-wake-race)).
